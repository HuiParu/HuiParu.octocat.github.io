天津中考「成绩 → 位次 → 可报院校」预测程序 · 设计说明

本文件写给后续实现该程序的开发者（人或 AI）。
目标：输入一名考生的中考升学总成绩与所在区，输出其全市位次、市内六区位次，并给出可报考院校清单（按 冲 / 稳 / 保 分档）。
所有数据源均为本地已整理好的 Excel 文件，路径见第 3 节。

1. 目标与范围

项目说明
输入score（升学总成绩，含政策照顾加分，0–800，可带小数）、district（考生所在区，如「和平区」「武清区」「滨海新区-塘沽」）、可选 year（参考年份，默认取最新一年）
输出 1全市位次（及位次区间）
输出 2市内六区位次（及位次区间）
输出 3可报考院校清单，含每校近三年录取线、对应位次、冲/稳/保标签
不做不预测当年分数线、不替代官方志愿填报系统；结论仅供决策参考

2. 核心方法论：为什么必须用「位次」而不是「分数」

各年试题难度与考生人数不同，同一分数的含金量逐年变化（例：2026 年 780 分以上 96 人，2025 年 203 人）。因此跨年比较院校录取线必须换算成位次：

  1. 用该年的一分一档表把「院校最低录取分」换算成「该年录取末位考生的位次」；
  2. 用同一张一分一档表把「考生分数」换算成「考生位次」；
  3. 两者在位次维度上比较，跨越年份可比。

前提：一分一档表本身已含政策照顾加分（源文件表头注明「含政策照顾加分」），因此输入的 score 必须是含照顾加分的升学总成绩，不得再加一次分。

3.1 一分一档表读取与归一化

# 分数档单元格形如 "775以上"，解析出下界整数 s；含义：成绩 >= s 的累计人数
def load_rank_table(path, sheet="Sheet1", col_city=1, col_zone=2):
    rows = []           # [(s, cum_city, cum_zone), ...]  按 s 降序
    for r in read_sheet(path, sheet)[1:]:        # 跳过表头
        s = int(str(r[0]).replace("以上", "").strip())
        rows.append((s, int(r[col_city]), int(r[col_zone])))
    return rows

注意 2025 表多一列（D 列 2024 年市内六区累计），是源表自带的历史对照列，预测时只用 B、C 两列。

3.2 录取线表的清洗规则

录取线表由图片誊录而来，存在以下非数值形态，解析时必须逐类处理，不得直接 float()：

形态示例处理
换行复合值721.95（市六区）\n718.85（全市）按考生所属范围取对应值（市内六区考生取「市六区」值，非市内取「全市」值）
区间排名2182-1960、2325-2301（市六区）取区间最差端（数值较大者）作为保守位次
未录满 / 录满未录满该年视为「无有效最低线」，跨年计算时该年跳过
占位符/、空串视为缺失，跳过该年
多区标注723.25（塘沽）\n720.15（新区）\n721.05（泰达）按考生所在细分区域匹配；无法匹配则跳过该校
征询相关一次征询钢线590.05、二次征询最低分573.3视为该年最低线（数值），并标记 via=征询

4. 算法

4.1 分数 → 位次（核心函数）

一分一档表给出的是整数分的累计人数。设

  • cum(s) = 成绩 ≥ s 的人数（由表直接查得，s 为表内整数）
  • 表内最高档为 S_max（如 780），最低档为 S_min（500）

对输入分 x：

若 x >= S_max:  位次上界 = 1，位次下界 = cum(S_max)      # 落在最高档内，只能给出区间
若 x <  S_min:  返回 None（表格未覆盖），提示"低于 500 分，无法定位位次"
否则:
    hi = ceil(x); lo = floor(x)
    若 lo == hi:  pos_hi = cum(hi) + 1 ; pos_lo = cum(hi)
    否则（x 为小数，假设该分区间内人数均匀分布）:
        位次 = cum(hi) + (hi - x) * (cum(lo) - cum(hi))
        pos_hi = round(位次) ; pos_lo = round(位次) - 1   # 保守区间 ±0
    返回 区间 [pos_hi, pos_lo]（pos_hi 为"最差排名"，pos_lo 为"最好排名"）

务实取法：对外只报 pos_hi（即"最差位次"），避免给家长过度乐观的估计。

全市位次 用 col_city；市内六区位次 用 col_zone。非市内考生若需「本区位次」，需该区单独的一分一档表（当前资料未提供，程序应返回「不可用」而非猜测）。

4.2 院校录取线 → 位次

对每所学校、每个有数据的年份 y ∈ {2024, 2025, 2026}：

score_y = 该校 y 年录取最低分（按 3.2 清洗后）
rank_y  = 4.1(score_y, year=y)   # 用「y 年的一分一档表」换算

得到 rank_2026 / rank_2025 / rank_2024 三个位次。这就是该年份被录取的末位考生位次（近似）。

4.3 冲 / 稳 / 保 分档

设考生位次 P（用 4.1 得到的最差位次），院校参考位次集合 R = {rank_y}（剔除缺失年份）：

R_sorted = 升序排列(R)                 # 位次数值越小越难考
r_best  = R_sorted[0]                  # 最难的一年
r_mid   = 中位数(R_sorted)
r_worst = R_sorted[-1]                 # 最简单的一年

若 P <= r_best             → 保   （三年中最难的一年也能进）
若 r_best < P <= r_mid     → 稳   （多数年份可进）
若 r_mid  < P <= r_worst   → 冲   （仅宽松年份可进，风险较高）
若 P >  r_worst            → 风险 （三年均够不到）

可选增强：把位次差换算成「安全边际」margin = (r_worst - P) / r_worst，输出百分比，便于排序：

  • margin ≥ 0.15 → 保
  • 0 ≤ margin < 0.15 → 稳
  • -0.10 ≤ margin < 0 → 冲
  • margin < -0.10 → 风险

两套判据二选一即可，推荐先用 R 分位法出档，再用 margin 排序。

4.4 可报性过滤（先过滤，再分档）

在 4.3 之前，必须先用任务 1 产出的招生范围表筛掉考生不能报的学校：

可报条件（满足其一）：
  1. 招生范围为「全市」
  2. 招生范围包含考生所在区（含市内六区考生的"市内六区"、滨海新区考生的"塘沽/汉沽/大港/油田/泰达/生态城/保税/高新"等细分）
  3. 民办校面向本区或面向全市的对应计划

户籍硬约束（规则见 天津中考规则简介.docx）：无本市常住户口且无蓝印户口的考生，不得填报普通高中志愿，程序应直接拒绝高中段预测并提示。

6. 校验与边界

6.1 必须内置的自校验

  1. 单调性：任一年一分一档表，分数档必须严格递减 1 分、累计数必须单调递增；否则数据文件损坏，直接报错。
  2. 反查一致性：对表中每一行 s，断言 ranker.rank_of(s, year).worst == cum(s)，全表 0 误差才算通过。
  3. 交叉印证：2025 表第 D 列「2024 年市内六区累计」应与 2024一分一档.xlsx 的市内六区列逐行一致（本次整理已确认首行 233、末行 33854 吻合）——可用于检测年份串档。
  4. 市内 ≤ 全市：任何分数下，市内六区累计数必须 ≤ 全市累计数。

6.2 已知数据疑点（程序应原样保留并在输出中提示）

  • 红桥区·瑞景中学 2026「市六区排名」源图为 2325-2301，与相邻行（2.5 万–2.8 万）明显不连续，疑似源图笔误。
  • 南开区·南大奥宇高级中学：2025 年全市线（585.2）高于市六区线（573.5）；2024 年全市线仅 424.2，波动异常。
  • 耀华滨海与一中滨海：塘沽线（723.25）与排名（1162-1127）完全相同，经放大核验为源图原样。

处理策略：不修正，但在 warnings 中提示「该校该年数据疑似异常，已按源图使用」。

6.3 不可用场景（明确返回不可用，不猜测）

  • 分数低于一分一档表最低档（500 分）→ 无法定位位次；
  • 考生所在区无对应一分一档表（非市内区想做「本区位次」）→ 返回「不适用」，仅给全市位次；
  • 院校近三年均无有效录取线 → 该校不参与分档，单独列入「数据不足」。
